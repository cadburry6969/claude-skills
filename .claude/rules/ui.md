# UI Rules

- Keep UI consistent with the existing design system.
- Reuse existing components and styles before creating new ones.
- Do not introduce arbitrary colors when existing theme variables are available.
- Avoid excessive animations.
- Animations should support usability rather than distract from the interface.
- Ensure interactive elements have clear hover, active, and disabled states.
- Handle loading, empty, and error states where applicable.
- Avoid unnecessary layout shifts.
- Keep responsive behavior in mind.
- Do not duplicate large blocks of CSS.
- Prefer existing utility classes and shared styling patterns.
